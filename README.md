# 🌟 Personal Portfolio Website

Hi! This is the source code for **Yarlagadda Setu Sai Ram’s Portfolio Website** — a modern, responsive personal site built with **React**, **Framer Motion**, **Tailwind CSS**, and **Iconify**.

## 🚀 Features

- 🎨 **Beautiful Hero Section**  
  An animated introduction with a profile picture, social links, and a downloadable resume.

- ⚡ **Dynamic Skills Showcase**  
  Grids displaying technical skills and additional tools with engaging hover animations.

- 🧩 **Available Roles**  
  Sections describing various roles I’m open to, along with my relevant skills and responsibilities.

- ✨ **Animated Backgrounds**  
  Subtle, moving shapes powered by Framer Motion for a visually pleasing experience.

- 📄 **Resume Download**  
  A button to view/download my latest resume directly from Google Drive.

- 🔗 **Social Links**  
  Easy access to my GitHub, LinkedIn, and Twitter profiles.

- 📱 **Responsive Design**  
  Fully responsive and dark mode ready.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Iconify](https://iconify.design/), [Lucide React](https://lucide.dev)
- **Styling:** [Tailwind CSS](https://tailwindcss.com)
- **Deployment:** Any static hosting (Vercel, Netlify, GitHub Pages)

## ⚙️ Installation & Setup

1. **Clone the repo**

   ```bash
   git clone https://github.com/yourusername/your-portfolio.git
   cd your-portfolio
````

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**

   ```bash
   npm run dev
   ```

   Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

## ✏️ Customization

* **Profile Picture:** Replace `/public/images/profile/setu3.jpg` with your own image.
* **Resume Link:** Update the `handleResumeDownload` URL in `About.tsx`.
* **Social Links:** Edit your social media URLs in the `socialLinks` array.
* **Skills & Roles:** Add or modify skills, tools, or available roles in `About.tsx`.
